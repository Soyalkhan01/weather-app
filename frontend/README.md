# 🌤 Weather App

A modern Full Stack Weather Application built using React JS, Flask, and WeatherAPI with live city search, dynamic weather data, search history, responsive UI, and backend API integration.

# 📌 Features

Live Weather Data  
Worldwide City Search Dropdown  
Dynamic Suggestions While Typing  
Search History  
Responsive UI Design  
Flask REST API Backend  
Full Stack Architecture  
API Integration  
Render Deployment  
Environment Variables Security
