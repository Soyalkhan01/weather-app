# 🌤 Weather App

A modern Full Stack Weather Web Application built using **React JS**, **Flask**, and **WeatherAPI**, featuring live city search, real-time weather updates, search history, responsive UI, and secure backend API integration.

# ⚙️ Installation

## 📥 Repository

```bash
git clone https://github.com/Soyalkhan01/weather-app
```

---

## 🖥️ Install Frontend

```bash
cd frontend

npm install

npm run dev
```

---

## ⚙️ Install Backend

```bash
cd backend

pip install -r requirements.txt

python app.py
```
